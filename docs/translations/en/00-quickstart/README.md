# Quickstart

Malebo is a luxury eyewear online store, modern, minimalist, and designed to deliver an elegant, sophisticated shopping experience.

It brings together an exclusive catalog of designer frames and sunglasses with a refined, high-performance interface.

Built around five core principles:

- **Clean Vanilla Stack:** Built with pure web standards (HTML5, CSS3, and modern ES6+ JavaScript), ensuring peak performance, minimal overhead, and zero heavy framework dependencies.
- **Curated Eyewear Catalog:** Explore exclusive collections of handcrafted frames, classic sunglasses, and precision-engineered smart glasses.
- **Modular CSS Architecture:** Component-driven styling utilizing CSS partials and native variables, facilitating effortless maintainability and theme customization.
- **Modern Developer Tooling:** Formatted with Biome JS and linted with ESLint, integrated with Husky pre-commit hooks and lint-staged to ensure consistent code quality.
- **Multi-Language Support:** Native localization and documentation across multiple languages, making the project accessible to developers and visitors worldwide.
