# Inicio Rápido

Malebo es una tienda online de gafas de lujo, moderna, minimalista y diseñada para ofrecer una experiencia de compra elegante y sofisticada.

Reúne un catálogo exclusivo de monturas y gafas de sol con una interfaz refinada y de alto rendimiento.

Construido en torno a cinco principios fundamentales:

- **Clean Vanilla Stack:** Desarrollado con tecnologías web puras (HTML5, CSS3 y JavaScript ES6+), garantizando el máximo rendimiento, ligereza y sin la sobrecarga de frameworks pesados.
- **Curated Eyewear Catalog:** Explore colecciones exclusivas de monturas artesanales, gafas de sol clásicas y gafas inteligentes de alta precisión.
- **Modular CSS Architecture:** Estilización componentizada mediante parciales de CSS y variables nativas, facilitando el mantenimiento y la personalización de temas.
- **Modern Developer Tooling:** Formateado con Biome JS e inspeccionado con ESLint, integrado con ganchos de pre-commit mediante Husky y lint-staged para asegurar la calidad del código.
- **Multi-Language Support:** Localización y documentación en múltiples idiomas, haciendo el proyecto accesible a desarrolladores y clientes de todo el mundo.
