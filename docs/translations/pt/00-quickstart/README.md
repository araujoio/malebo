# Início Rápido

O Malebo é uma loja online de óculos de luxo, minimalista, moderna e projetada para oferecer uma experiência de compra elegante e sofisticada.

Ele reúne um catálogo exclusivo de armações e óculos de sol com uma interface refinada, visual marcante e alta performance.

Construído em torno de cinco princípios fundamentais:

- **Clean Vanilla Stack:** Desenvolvido com tecnologias web puras (HTML5, CSS3 e JavaScript ES6+), garantindo máxima performance, leveza e sem a sobrecarga de frameworks pesados.
- **Curated Eyewear Catalog:** Explore coleções exclusivas de armações artesanais, óculos de sol clássicos e óculos inteligentes de alta precisão.
- **Modular CSS Architecture:** Estilização componentizada através de CSS partials e variáveis nativas do CSS, permitindo fácil manutenção e customização de temas.
- **Modern Developer Tooling:** Formatado com Biome JS e inspecionado com ESLint, integrado a hooks de pré-commit com Husky e lint-staged para garantir qualidade e padronização de código.
- **Multi-Language Support:** Localização e documentação em múltiplos idiomas, tornando o projeto acessível para desenvolvedores e clientes de todo o mundo.
